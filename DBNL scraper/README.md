# CCLAMP_DBNL-scraper
This Python script can be used to scrape DBNL author landing pages.

To do so, you need the authors' unique DBNL identifiers and the links to their pages, e.g., such as in `author_identifier_list.txt`.

The Python script stores all scraped pages into the `scraped_json` folder and keeps track of failed scrapes in `failed_scrapes.csv`.
The results can be found in the folder DBNL scraped (CCLAMP_Metadata/DBNL scraped)
